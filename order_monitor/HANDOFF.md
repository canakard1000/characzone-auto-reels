# 오너클랜 주문·송장 Telegram 점검 인수인계
상태: 코드와 모의 테스트 완료, 운영 연결 미완료. 예약 실행 비활성.

## 구현
- 오너클랜 공식 GraphQL allOrders 조회, 최근 90일 내역 전체 페이지 처리.
- 수량, 발주 코드, 상태, 택배사, 송장번호만 Telegram으로 전송. 이름·주소·전화번호는 조회하지 않음.
- 기존 TELEGRAM_BOT_TOKEN / TELEGRAM_CHAT_ID를 GitHub Secrets에서 재사용.
- 조회 오류·응답 오류·페이지 오류·인증값 누락은 주문 없음으로 처리하지 않음.
- Telegram ok:true 및 message_id가 있어야 전송 확인. 민감정보 포함 URL 및 오류 본문 로그 금지.
- 6개 모의 테스트 통과. 실 API 조회·Telegram 전송은 미검증.

## 운영 연결 차단점
1. OWNERCLAN_JWT를 GitHub Secrets에 보안 입력해야 함. 비밀번호나 토큰을 채팅으로 요청하지 않음. 기존 브라우저 세션 추출 금지.
2. 공식 주문 API는 이미 오너클랜에 발주한 주문만 조회. AI셀러봇에 나타나는 미발주 쇼핑몰 새 주문 조회는 별도 공식 연동이 필요하며 미구현.
3. JWT 만료 전 갱신 필요. 만료/권한 오류는 점검 실패로 보고해야 함.
4. 수동 실행으로 실제 API 조회 성공 및 사용자의 기존 Telegram 수신처 도착 검증 후 schedule 주석 해제.
5. 준비된 cron은 UTC 00:20/03:20/... = 한국시간 00:20/03:20/06:20/09:20/12:20/15:20/18:20/21:20. GitHub Actions 특성상 지연 가능, 정확한 정시 보장 안 됨.
